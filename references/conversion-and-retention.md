# 私聊转化、售后与复购唤醒

用于当下回复、对话手册、销售陪练、老客经营与流失挽回。按客户真实表达推进，不追求机械完成话术链。

## 当下的一条回复

先读最近上下文、来源、客户原话、当前需求、已给承诺与价格。通常给一条推荐回复，必要时提供两个不同语气版本，并用一句话说明希望确认什么。不要默认输出整份销售手册。

客户问明确事实时先答能确定的部分。例如问价格且已有价目，直接给价格和包含项；不同配置价格不一时给真实范围与影响条件，再问一个必要问题。不能以“先挖需求”为由故意回避价格。

缺少关键事实时，回复中只承诺去确认，并在成稿外提示经营者需要核实的事项。客户姓名、产品、金额和既往互动必须可追溯，不能为“个性化”虚构共同经历。

## 按阶段设计分支

| 阶段 | 目标 | 对话动作 | 转向/停止 |
|---|---|---|---|
| 新联系 | 让对方知道你是谁、为何联系 | 回应来源，交付已承诺价值，问易答的问题 | 来源不明先确认，不连发资料 |
| 了解需求 | 判断场景和适配 | 从用途到现状、顾虑、计划时间或预算逐步问 | 每轮一两个问题，避免盘问 |
| 推荐与报价 | 支持比较和决定 | 复述需求，给适合方案、价格、包含项与限制 | 不适用就说明，不硬推 |
| 异议 | 找到真实障碍 | 认可顾虑，确认具体问题，给事实或替代选择 | 无证据不能承诺效果 |
| 下一步 | 形成低负担进展 | 选择一个预约、演示、试用或确认动作 | 没有需求则体面结束 |
| 成交后 | 确保交付和使用 | 订单、履约、注意事项、服务入口 | 退出未购催单与首购优惠 |

完整手册使用“触发话语/状态 → 适用回复 → 需要的证据 → 下一步 → 退出条件”。销售负责人或资深一线的真实异议记录比臆造的“成交秘籍”更可靠。

### 常见异议

- 太贵：问清比较的是总价、配置还是当下预算，说明真实包含项，可给缩小范围或延后选择。
- 再考虑：轻问最需要弄清的一件事，客户不愿说明则接受其节奏。
- 别家便宜：比较可核实的交付、服务和适配，不贬低竞品或编造质量问题。
- 需要别人共同决定：提供简洁方案供转述，是否共同沟通由客户决定。
- 不信任：给可核验资料与真实边界；没有证据时承认不知道，不用“案例图”掩盖事实缺口。
- 不需要本次产品：停止对应推介，记录需求变化；明确说别联系或退订营销时，按其表达范围停止营销，不能换号或换渠道继续追。

每条微信话术一般短而可读，字数按信息完整性调整；不要为了 80 字上限省掉关键价格条件或风险说明。

## 无回应跟进

先检查客户是否约定了联系时间、此前触达次数、跨活动冲突和服务状态。跟进必须提供新的相关价值，不能每次只问“考虑好了吗”。

为本轮方案明确每个联系节点、最大无回应次数和结束条件，依据客户偏好、决策周期、历史响应及跨活动累计触达确定。D1/D3/D7 可以是短周期业务的候选排期，但要解释保留哪些节点及取消条件；没有约定或依据时采用低频小范围试点，不固定要求联系两次或三次。

已回复就转入当前对话，已成交则转入交付，拒绝后停止相应营销，出现售后问题先处理服务。长决策周期按客户约定联系，不机械按自然日催单。

## 售后与反馈

先完成使用指导、履约确认和真实问题处理，再考虑复购与推荐。出现投诉时：确认事实与诉求 → 记录订单或问题 → 指派负责角色与反馈时限 → 跟进是否解决。赔付和退款只按已授权条款办理；不以优惠券代替问题解决。

FAQ 按真实客户问题组织：标准回答、适用条件、来源或维护日期、需要人工判断的情形。训练营可给解释与练习，但不能假装掌握不存在的课程内容；医疗等专业问题转交合适的专业人员，运营话术不做诊断或功效保证。

## 复购与沉睡客户

先按 [客户分层](customer-segmentation.md) 确定周期、购买数据和可联系范围。将退订与售后暂停对象排除出营销；已再次下单者重新计算周期；未购线索走需求培育；关键数据不全者列入待核实名单，不直接放入沉睡唤醒。

为每层确定一种主目标：确认使用情况、发现新需求、到期补货、续费或恢复沟通。高价值但有负面体验的客户，先修服务而非加大优惠。

| 字段 | 要给出的内容 |
|---|---|
| 入选依据 | 上次产品、距购买时间、正常周期与有效记录 |
| 优先级 | 真实需求可能性、服务紧迫性、资源和贡献 |
| 提供的价值 | 使用支持、补充资料、相关新品或已批准权益 |
| 触达设计 | 每个节点的目标、时间、渠道、负责人、原句 |
| 承接分支 | 有问题、只说谢谢、问活动、已有替代、没需求 |
| 退出条件 | 回复、复购、拒绝、预算用尽、达到无回应次数 |

优惠只是可选手段，成本包含折扣、赠品、配送与人工。未知未来复购不能填进收益保证。基于历史购买的句子必须用真实字段；只有一笔模糊记录时不能写“您一直支持我们”。

对“谢谢”可轻问是否还需要资料，对活动询问直接说明真实资格和价格，对明确不需要则收尾。不要把礼貌回复自动升级成高意向。

## 陪练与话术迭代

用户要求陪练时，明确扮演的客户与情景，每次一轮对话。反馈以需求判断、回应准确性、证据、提问负担和下一步是否合适为依据；不声称某种话术必然成交。将真实有效表达沉淀到用户的现有话术库，不能擅自把其他客户隐私写入通用模板。
