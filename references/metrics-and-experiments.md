# 指标口径、漏斗分析与实验

用于任何数据计算、目标拆解、ROI、活动或渠道比较。先定义口径，再计算；数据缺失不能用参考案例补齐。

## 先检查数据能否比较

固定统计周期、时区、去重客户 ID、订单 ID、订单有效状态、退款处理、事件顺序、币种和渠道归因。区分客户数、订单数、消息数和活动参与次数。

同一客户跨群、跨员工和跨活动出现时去重；多个表连接前检查一对多，避免订单被聊天记录行数放大。核对重复订单、缺少身份关联、未来日期和负净额的原因。负值可能是合法退款，不自动删除、改为零或当作错误订单。

跨来源对比需同时看客户构成、进入时间、观测时长与费用范围。高价值客户本就被分到 VIP 群，不能仅凭该群转化率高就断言“VIP 服务导致四倍提升”。

## 一个可核对的经营分解

在固定客户集合和窗口内，定义：

- N：被观察的去重客户数。
- c：该集合中有至少一个有效订单的客户数 / N。
- f：有效订单数 / 购买客户数，**包含首单**。
- a：该口径下收入 / 有效订单数。

则收入 = N × c × f × a。采用退款后收入时应称为净收入并明确订单处理；GMV 单独定义。收入、购买客户和订单须属于同一集合；按退款发生日扣除的跨期退款要单列调节，不能硬塞入仅含本期订单的等式。f 包含首单，单次购买用户不会被错算为零收入。没有购买客户时相关比率标为不可计算。

示例：100 名客户、20 名购买者、25 笔有效订单、每单 200 元，则 f=1.25，收入=5,000 元。该等式用于核账，不证明增加任一因子一定不会影响其他因子。

## 漏斗与同批客户

选业务真实路径，如有效线索 → 成功建立联系 → 首次有效沟通 → 明确需求 → 有效首购。入群只在业务确有该步骤时纳入。

计算同一批次、在规定时间内依次达成的事件人数。后一步应是前一步的子集；客户可以绕过的步骤不能强塞进单一路径。月新增好友和月全部成交者来自不同人群时，只能作为并列运营量，不能相除称新客转化率。

没有用户级事件记录时，说明只能做粗略趋势或并列指标。漏斗的下降点说明发生了什么，原因还需用内容、对话或服务记录验证。

## 常用指标字典

| 指标 | 建议定义 | 注意事项 |
|---|---|---|
| 新增有效联系人数 | 周期内首次有效建立联系的去重客户数 | 区分重复添加与新客户 |
| 首次有效回复率 | 同批新增客户中窗口内有效回复人数 / 该批符合观察条件人数 | 不用发送成功或自动欢迎代替回复 |
| 群有效参与率 | 窗口内符合预定义参与行为的非管理员独立人数 / 明确的成员基数 | 说明成员基数是期初还是期间成员；不当成阅读率 |
| 新客首购率 | 某新增批次在加入后 X 天内有效首购人数 / 已满 X 天观察的该批人数 | 未满观察期单列，不能与完整窗口混算 |
| 复购率 | 某首购批次在首购后 X 天内发生第二次有效购买人数 / 满 X 天观察的该批人数 | 窗口内老客订单占比是另一指标 |
| 客单价 | 同口径收入 / 有效订单数 | 不是收入 / 好友人数 |
| 删除或退订率 | 周期内符合该事件的去重人数 / 明确的可联系基数 | 先确认事件是否可观测；退群不等于删除 |
| 唤醒回复率 | 入选并实际触达的去重对象中有效回复人数 / 实际触达人数 | 未知送达不能默认为已收到 |
| 触达后购买率 | 实际触达对象中窗口内购买人数 / 实际触达人数 | 是观察关联，不等于增量效果 |
| 推荐有效新客率 | 去重有效新客 / 可核验去重推荐线索 | 分享次数、访问量和人数不能混用 |
| CAC | 明确范围的渠道成本 / 归因窗口内该渠道新增付费客户数 | 如只算加好友成本，另命名为有效联系成本 |
| 观察期客户贡献 | 同批客户在 X 天内收入减去对应商品与变动履约成本，再除以客户数 | 说明是否扣营销费用；不是完整终身价值 |

分母为零记“不可计算”，不是 0%；缺字段记“缺数据”，不是表现差。每个指标随结果列出分子、分母、窗口、数据来源和缺失项。

## 利润、ROI 与预算

区分销售额、净收入、毛利、贡献和净利润。没有成本数据时可以报告收入，不能把它直接命名为 ROI。

一种透明口径：

```text
净收入 = 同一统计范围内的实际成交收入 - 尚未扣除的退款
营销前贡献 = 净收入 - 对应商品成本 - 变动履约成本
活动投入 = 本活动的奖励、获客素材、渠道费用和执行人工等未在上式扣除的成本
活动观察回报率 = (归因到活动的营销前贡献 - 活动投入) / 活动投入
增量 ROI = (活动带来的增量营销前贡献 - 增量活动投入) / 增量活动投入
```

实际成交收入通常已经包含优惠后的价格；若原始表是折扣前金额，先扣折扣转换口径。退款若已在原始净额中扣过，不再扣第二次。赠品、物流和人工也只在选定成本位置计算一次。说明固定工资按分摊工时计入还是仅计增量现金支出。

归因购买包括本来就会发生的自然购买；没有对照或可信反事实时只报告观察回报，不能声称增量 ROI。

示例：净收入 10,000 元，对应商品与履约成本 6,000 元，活动投入 1,000 元，则观察回报率=(4,000−1,000)/1,000=300%。该数字不证明活动额外创造了 3,000 元，仍需对照估计自然基线。投入为零时不显示无限 ROI。

LTV 必须区分观察期收入、观察期贡献和预测终身贡献；预测需写假设、覆盖期与不确定性。不把“LTV/CAC 大于 3”或“半年回本”作为所有品类的统一合格线。

## 从诊断到实验

按影响程度、证据强度、实施成本和风险排序，先测试一两个关键假设。每个实验给：入选客户、排除名单、当前基线、单一主要改动、主要指标、退订/投诉/退款等保护指标、所需数据、观察窗口、负责人和结束条件。

可行时按客户随机分组，保持相同观察时间且避免一个客户进入两个组。群内互动相互影响明显时考虑按群或门店分组，并说明样本与组间差异。没有对照的前后比较只能作为线索。

小样本给原始人数与不确定性，不以两三个转化就宣布“已证明”；不能为了得到显著结果不断改窗口或只挑好看的指标。业务周期未满时先报告过程结果。

## 周/月复盘交付

回答四件事：发生了什么、证据支持哪些原因、哪些还未知、下一轮具体改什么。每个动作配负责人、检查时间、评价口径和停止条件；无新证据时不要每周推翻全套体系。
